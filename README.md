# 💰 Calculadora de Economia

Meu primeiro projeto em Python.

## Sobre

Esta calculadora ajuda a acompanhar uma meta financeira.

Ela informa:

- 💵 Quanto falta para atingir a meta.
- 📈 Percentual concluído.
- ⏳ Tempo estimado para alcançar a meta.
- 🎯 Mensagens motivacionais conforme o progresso.

## Tecnologias

- Python 3

## Como executar

Clone o projeto:

```bash
git clone https://github.com/Brazzin/calculadora-de-economia.git
```

Depois execute:

```bash
python calculadora.py
```
