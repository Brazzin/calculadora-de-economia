# 💰 Calculadora de Economia

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![Status](https://img.shields.io/badge/Status-Em%20Desenvolvimento-green)

Meu primeiro projeto desenvolvido em Python durante meus estudos de programação.

---

## 📌 Objetivo

A Calculadora de Economia ajuda o usuário a acompanhar uma meta financeira.

Ela informa:

- 💵 Quanto falta para atingir a meta.
- 📈 Percentual já concluído.
- ⏳ Tempo estimado para atingir a meta.
- 🎯 Mensagens motivacionais conforme o progresso.

---

## 🚀 Funcionalidades

✔ Calcular quanto falta para atingir uma meta.

✔ Mostrar o percentual concluído.

✔ Estimar quantos meses faltam.

✔ Informar quando a meta foi alcançada.

✔ Tratar erros como divisão por zero.

---

## 🖥️ Tecnologias

- Python 3

---

## ▶ Como executar

Clone o projeto:

```bash
git clone https://github.com/Brazzin/calculadora-de-economia.git
```

Entre na pasta:

```bash
cd calculadora-de-economia
```

Execute:

```bash
python calculadora.py
```
